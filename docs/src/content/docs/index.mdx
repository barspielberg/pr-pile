pile fetches every open PR for a repo and renders each as one line, ordered by
rules you write. It opens PRs in the browser, shows the checks and review state
that decide what to do next, and gets out of the way between uses.

<CardGrid stagger>
  <Card title="Rules are the board">
    A PR is shown under the first rule that matches it, so ordering is the
    configuration. Four starter rules ship out of the box.
  </Card>
  <Card title="One keypress, one line">
    Every row is exactly one line, so scrolling is steady and predictable, and a
    header is a position the cursor can sit on.
  </Card>
  <Card title="Detail overlay">
    Failing checks, conflicts, reviewers and size are one key away — `d` — not
    in the list.
  </Card>
</CardGrid>

## Install

On macOS, use Homebrew:

```sh
brew install barspielberg/tap/pile
```

macOS and Linux, `gh` logged in, Go 1.24.2+ to build from source. See
[Install](getting-started/install/) for source installs, Linux downloads, and
the macOS browser-download limitation.

## Status

A personal tool at 0.x with stable
[v0.1.0](https://github.com/barspielberg/pr-pile/releases/tag/v0.1.0) released;
these docs track `main`. Public Homebrew installation and interactive checks
passed on macOS Apple Silicon. CI builds and automated tests run on Linux and
macOS. Public upgrades, Linux release installation/desktop integrations, and
other native architectures remain unvalidated.
