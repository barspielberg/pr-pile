pile fetches every open PR for a repo and renders each as one line, ordered by
rules you write. It opens PRs in the browser, shows the checks and review state
that decide what to do next, and gets out of the way between uses.

```text
MINE (2)
  ▌ #143 add --since flag to the sync command    ✓ ✓ ✓    imm
    #141 stop double-fetching the rollup           ◐       jdo

NEEDS MY REVIEW (1)
    #138 drop the per-rule timeout                 ✗       amb

ALL OPEN (3)
    ...
```

## Install

```sh
go install github.com/barspielberg/pr-pile/cmd/pile@latest
```

macOS today, `gh` logged in, Go 1.24+ to build from source. See
[Install](/getting-started/install/) for the Homebrew and checkout options.

## Status

A personal tool at 0.x with no tagged releases yet; these docs track `main`.
Tested on macOS. Not built: write actions, multi-repo, a preview pane.
